Quick Start

Get OGrammar up and running in 5 minutes!

5-Minute Setup

Follow these steps to get OGrammar running quickly. You'll need an API key for the best experience.

Step 1: Get Your API Key (Optional but Recommended)

For the best grammar checking experience, you'll need an API key. We recommend Groq for its free tier:

  1. Visit Groq Console
  2. Sign up / Log in
  3. Go to API Keys → Create API Key
  4. Copy your key (starts with gsk_)
Free tier: Groq's free tier is generous (rate-limited) — plenty for everyday writing. Prefer no key at all? Run Ollama locally.

Step 2: Build the Extension

bash 
# Clone the repository
git clone https://github.com/zazzn/ogramext.git
cd opengrammar/opengrammar/extension

# Install dependencies
npm install

# Build the extension
npm run build

This creates a dist/ folder with the built extension.

Step 3: Load in Your Browser

Chrome / Brave / Edge

  1. Open chrome://extensions/ (or brave://extensions/ / edge://extensions/)
  2. Enable Developer mode (toggle in top-right)
  3. Click Load unpacked
  4. Select the opengrammar/extension/dist folder
  5. Extension loaded! You'll see the OGrammar icon

Brave Browser

  1. Open brave://extensions/
  2. Enable Developer mode (top-right)
  3. Click Load unpacked
  4. Select opengrammar/extension/dist folder
  5. Extension loaded!

Microsoft Edge

  1. Open edge://extensions/
  2. Enable Developer mode (left sidebar)
  3. Click Load unpacked
  4. Select opengrammar/extension/dist folder
  5. Extension loaded!

Mozilla Firefox

️
Note: Firefox support is temporary. The extension must be reloaded each time you restart Firefox.
  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on
  3. Navigate to opengrammar/extension/dist
  4. Select manifest.json
  5. Extension loaded!

Step 4: Configure

  1. Click the OGrammar icon in your toolbar
  2. Click Settings (gear icon)
  3. Enter your API key (from Step 1)
  4. Select Provider: Groq
  5. Keep the default model, or pick llama-3.3-70b-versatile for the fastest replies (or run Ollama locally with qwen3.5:4b)

Step 5: Start Writing!

  1. Open any text box (Gmail, Google Docs, Notion, etc.)
  2. Type something with a grammar error: me and him went to store
  3. You'll see a red underline under the error
  4. Click it to see the suggestion: he and I went to store
  5. Click Apply to fix it!

What is OGrammar?

Your privacy-first, open-source writing assistant

Why OGrammar?

Most popular grammar assistants require you to send every keystroke to their servers and charge a hefty monthly fee for advanced features. OGrammar changes that.

Key Features

Zero Cost Option

The core engine runs locally in your browser, checking grammar, spelling, punctuation, and style without needing a server or an internet connection.

Bring Your Own AI

Just paste in your own API key (like OpenAI, Groq, or OpenRouter). You pay only fractions of a cent for what you actually use, directly to the AI provider.

Absolute Privacy

We don't have a database, servers, or user accounts. Your API key never leaves your browser. If you use the AI features, your text is sent directly to the provider you chose — there is no OGrammar backend in between.

Open Source & Local-First

On-device grammar runs with no key or network. For AI, bring your own provider key or run a local model with Ollama — you stay in control.

Features

  • Works Everywhere: Seamlessly integrates into text inputs, textareas, and rich text editors (like Gmail, Google Docs, Notion, and Reddit).
  • Blazing Fast: Built with modern web technologies (React, Vite, Manifest V3) for minimal performance impact.
  • Dual-Engine Architecture:
    • On-device (Free & Offline): The Harper engine checks grammar, spelling, punctuation, and style — including repeated and filler words.
    • AI-Powered (Optional): Advanced grammar, spelling, clarity, and stylistic rewrites — with your own provider key, or a local model via Ollama (no key, and nothing leaves your device).
  • Tone & Style Rewriting: Select text and rewrite it inline in one of three tones — Polish, Formal, or Casual (AI required).
  • Intuitive UI: Familiar red, yellow, and blue underlines with click-to-apply suggestions.

AI Provider Setup

Configure AI providers for advanced grammar checking and tone rewriting.

Overview

OGrammar is bring-your-own-key: it calls your chosen provider directly with your own key — there is no OGrammar backend. The local Harper engine always works without a key; a provider only powers the optional LLM tier (sentence-level review and tone rewriting). The scores below are measured on OGrammar's own 46-case proofreading corpus (out of 123) with protected-text masking on — see the full provider guide for the methodology.

Ollama (local)

Score: 123/123
Speed: ~1s (GPU)
Cost: Free

Private & offline. Model qwen3.5:4b — the shipped default and best local result tested.

DeepSeek

Score: 123/123
Speed: ~1–2s
Cost: ~$0.00004/correction

Best overall quality and cheapest cloud among the models we tested. Model deepseek-chat.

Groq

Score: 97–117/123
Speed: ~0.4s
Cost: Free tier

Lowest latency. llama-3.3-70b-versatile (fastest) or gpt-oss-20b (best quality).

Also supported: OpenAI, OpenRouter, Together AI, Abacus RouteLLM (flat ~$10/mo, route-llm), and any OpenAI-compatible Custom endpoint. The table above is a small benchmark of only a few models — OpenAI and most other models were not scored, so their absence isn't a verdict on quality. They work well; use whichever provider you already have.

Ollama — private & free (recommended)

  1. Install from ollama.com, then run ollama pull qwen3.5:4b.
  2. In Settings: Provider Ollama, Base URL http://localhost:11434/v1, Model qwen3.5:4b, leave the API key empty.
  3. Ollama in WSL? Use http://127.0.0.1:11434/v1 — Windows resolves localhost to IPv6, which WSL's loopback doesn't forward.

DeepSeek — best quality + cheapest

  1. Create a key at platform.deepseek.com.
  2. In Settings: Provider DeepSeek, paste the key, Model deepseek-chat.

Groq — fastest cloud (free tier)

  1. Create a key at console.groq.com (starts with gsk_).
  2. In Settings: Provider Groq, paste the key, Model llama-3.3-70b-versatile (fastest) or gpt-oss-20b (best quality).

Tone Rewriting

Master the art of rewriting text in different tones.

Available Tones

Formal

Use for: Academic writing, business proposals, official communications

Input: hey whats up
Output: Greetings, how are you?

Casual

Use for: Social media, text messages, informal emails

Input: Greetings, how are you?
Output: Hey, what's up?

Polish

Use for: Tightening any draft — fixes flow and wordiness while keeping your voice

Input: i just wanted to maybe ask if we could possibly meet
Output: Could we meet?

How to Use

Tone rewriting requires AI to be configured. It works entirely from the in-page selection bubble — there is no right-click menu and no keyboard shortcut.

  1. Select the text you want to rewrite
  2. A floating bubble appears next to your selection
  3. Choose a tone: Polish, Formal, or Casual
  4. Review the rewrite and apply it

⌨️ Keyboard Shortcuts

All keyboard shortcuts for quick access to OGrammar features.

Keys in the Browser Extension

OGrammar keeps its keyboard surface deliberately small. These are the only two keys it uses, and they apply to the autocomplete ghost-text suggestion:

Key Action
Tab Accept the current autocomplete suggestion
Esc Dismiss the suggestion card / autocomplete
No global shortcuts.

The extension registers no global keyboard commands. Applying a correction, rewriting a tone, ignoring a suggestion, and adding a word to your dictionary all happen inline from the suggestion card and the selection bubble. Settings open from the popup.

Troubleshooting

Solve common OGrammar issues with this comprehensive guide.

Common Issues

No Grammar Highlights

Symptoms

  • Typing text with errors
  • No red/amber/blue underlines appear
  • Extension icon shows no error count

Solutions

  1. Check extension is enabled
  2. Verify site is not in disabled domains
  3. Reload the page
  4. Check browser console (F12) for errors

Provider Connection Failed

Symptoms

  • Red status indicator in extension
  • "Cannot connect to provider" error
  • No AI suggestions

Solutions

  1. Verify the selected provider, model, and API key in settings
  2. For Ollama/Custom, check the base URL is reachable
  3. Check firewall settings

AI Not Working

Symptoms

  • On-device checks work
  • AI suggestions don't appear
  • "API key invalid" error

Solutions

  1. Verify API key is entered correctly
  2. Check for typos (no spaces)
  3. Ensure correct provider is selected
  4. Test API key with provider directly
  5. Check rate limits (Groq's free tier is rate-limited)

Frequently Asked Questions

Common questions about OGrammar.

Is OGrammar really free?

Yes! The core on-device Harper engine is completely free and works offline. For AI-powered features, you bring your own API key and pay only for what you use directly to the provider (often fractions of a cent).

How does OGrammar protect my privacy?

OGrammar has no databases, no user accounts, and no tracking. Your API key never leaves your browser. When using AI features, text is sent directly from your browser to the AI provider you chose, using your own key — OGrammar has no servers, so it never sees or stores your text.

Which AI provider should I use?

For privacy and zero cost, use Ollama locally with qwen3.5:4b. For the best quality at the lowest price, use DeepSeek (deepseek-chat). For the fastest cloud responses, use Groq (llama-3.3-70b-versatile). See the AI Providers page for measured scores.

Can I use OGrammar without internet?

Yes! The on-device Harper engine works completely offline. For AI features, you can use Ollama to run models locally on your machine, giving you full offline capability.

Does OGrammar work on Google Docs?

Yes, OGrammar works on Google Docs and most rich text editors. Google Docs support is actively being improved for better compatibility.
